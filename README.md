## 🌟 Executive Overview

**Portfolio OS** is an interactive web-based operating system designed to showcase my engineering projects, AI research, hackathon wins, and technical capabilities. Blending a **macOS Sequoia desktop interface** (featuring an Apple menu bar, Control Center, and spring-physics dock) with a **retro-futuristic zsh terminal CLI**, it offers visitors a hands-on interactive experience.

## ✨ Key Features

- 🍎 **macOS Sequoia Desktop Environment**:
  - Live Apple  Dropdown Menu with Quick Settings & System Info.
  - Interactive Control Center with Wi-Fi, Bluetooth, Dark Mode, and Live Date/Time.
  - Glossy Squircle Dock with **120 FPS spring physics magnification** (`stiffness: 400`, `damping: 25`).
- ⌨️ **Interactive Zsh Terminal Engine**:
  - Smart autocomplete dropdown (`/`) with arrow key keyboard navigation.
  - Command History buffer (Up/Down arrow key recall).
  - Sound effects, Matrix rain easter egg (`/matrix`), and interactive prompts.
- 🎨 **Dynamic Theme & Wallpaper Engine**:
  - 5 high-definition visual wallpapers (*Cyber Mountains*, *1983 Retro Grid*, *Cyberpunk Metallic Shards*, *Cosmic Nebula*, *Glassmorphism*).
  - Custom neon ASCII portrait generation.
- 🏆 **Comprehensive Project Portfolio**:
  - 8+ full-stack AI, computer vision, and web projects with live URLs, GitHub source links, and tech stack badges.
- 📱 **100% Fully Responsive & Accessible**:
  - Fluid typography (`clamp()`), mobile keyboard support, screen-reader headings, and optimized Web Vitals.

## ⚡ Interactive CLI Commands

You can interact with the portfolio using the built-in terminal CLI or top navigation menu:

| Command | Shortcut / Action | Description |
| :--- | :--- | :--- |
| **`/about`** | Click **About** | Bio, academic background (IIT Guwahati & MSIT), and career highlights. |
| **`/work`** | Click **Projects** | Browse 8+ flagship projects (*TruthLens AI*, *Sentinel AI*, *GRAVITAS*, *FarmIQ*, etc.). |
| **`/skills`** | Click **Skills** | Technical stack broken down by Build, Store, Ship, and AI ML frameworks. |
| **`/contact`** | Click **Contact** | Direct contact form & email parameters. |
| **`/social`** | Click **Socials** | Quick links to GitHub, LinkedIn, Twitter/X, and Devpost. |
| **`/themes`** | Click **Themes** | Open theme switcher (*Cyber Mountains*, *Retro*, *Dark*, *Space*, *Glass*). |
| **`neofetch`** | System Specs | Output macOS System Specifications and hardware environment. |
| **`/matrix`** | Easter Egg | Trigger matrix green code rain overlay (press `ESC` to exit). |
| **`/clear`** | Clear Screen | Reset terminal logs and wipe screen buffer. |
| **`/help`** | Command List | Print all active system protocol commands. |

## 💻 Local Installation & Setup

Want to run this operating system locally on your machine?

```bash
# 1. Clone the repository
git clone https://github.com/JayantOlhyan/Jayant-Olyan-Portfolio-2-.git

# 2. Enter project directory
cd "Jayant-Olyan-Portfolio-2-"

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser to access the system kernel!
